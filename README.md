# GuaipeCare 🐾

Demonstração de uma coleira comunitária com perfis de animais, fotos, cuidados e contatos dos responsáveis.

Acesse o site em [lusaas.github.io](https://lusaas.github.io/) ou abra `index.html` no navegador. As páginas usam HTML e CSS; as fotos externas do Caramelo precisam de internet.

Esta versão estática não solicita localização nem registra avistamentos. Para alterar os perfis, edite os arquivos HTML correspondentes.
